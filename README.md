## 🔍 4. 분석 절차 요약

- 병합된 셀 처리(Fill-Forward)

## 📈 5. 주요 분석 결과

### 🔹 **1) 음주율과 범죄율**
- 음주율과 범죄율은 **약한 양의 상관관계(weak positive correlation)** 를 보임.
- 즉, **음주율이 높을수록 범죄율도 약간 증가하는 경향**이 존재함.

### 🔹 **2) 고위험 음주율과 범죄율**
- 상관계수 ≈ **0**에 가까움 → 유의미한 관계 없음.
- 회귀선 기울기도 거의 존재하지 않음.
- 즉, **고위험 음주율이 높다고 해서 범죄율이 비례해 증가하지는 않음.**

### 🔹 **3) 지역별 특징**
- 범죄율 Top10 지역은 인구 대비 범죄 발생이 높은 지역적 특성이 존재.
- 음주율/고위험음주율 Top10과 반드시 일치하지 않음 → **다른 구조적 요인의 영향이 큼.**

## 🧪 6. 의미 및 시사점

- 단순 음주율만으로 범죄율을 설명하기 어렵다.
- 고위험 음주율은 더욱 설명력이 낮음 → 정책적으로 개선 여지가 있음.
- 범죄율은 **유동 인구, 도시 규모, 지역 특성** 등 다양한 요인과 함께 분석되어야 함.
- 향후 **다변량 회귀분석 또는 머신러닝 기반 예측 모델**로 확장 가능.
