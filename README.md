## 📈 5. 주요 분석 결과

### 🔹 1) 음주율과 범죄율
- 전체적인 경향에서 **약한 양의 상관관계**가 나타났습니다.
- 즉, **음주율이 높은 지역일수록 범죄율이 약간 증가하는 경향**이 있음.

### 🔹 2) 고위험음주율과 범죄율
- 상관계수 ≈ 0에 가까움 → **거의 상관 없는 수준**
- 회귀선 또한 기울기가 미미하여 유의미한 관계가 보이지 않음.

### 🔹 3) 지역별 특징
- 범죄율(10만명당) Top10 지역들은 인구 대비 범죄량이 높은 구조적 특징을 보임.
- 음주율/고위험음주율 Top10 지역과 반드시 일치하지는 않음 → **개별적 특성 존재**

## 🧪 6. 의미 및 시사점

- 단순 음주율이 범죄를 직접적으로 설명하는 강력한 지표는 아님.
- 고위험 음주율은 더욱 설명력이 낮음 → 정책 개입 지점이 명확함
- **범죄율은 여러 복합 요인(유동인구, 도시 규모 등)이 함께 작용하는 것으로 판단됨.**
- 향후 다변량 회귀분석 또는 머신러닝 기반 예측 모델을 적용해볼 수 있음.
